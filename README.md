# 로그 이미지 생성기

대사와 지문을 조판해 이미지로 저장하는 웹 도구입니다. 롤플레이 로그, 대화, 발췌문을 꾸며 PNG·JPG로 내보낼 수 있습니다.

순수 모노톤 인터페이스에 라이트/다크 모드를 지원하고, PC와 모바일 모두에 맞게 화면이 조정됩니다. 설정과 작성 내용은 브라우저에 자동 저장됩니다.

## 화면 구성

로그 입력창은 항상 상단에 고정되어 있고, 그 아래 네 개의 탭으로 옵션이 나뉩니다.

- **내용** — 하단 정보(이름·날짜 등), 하단 배치, 글꼴
- **디자인** — 기본/보조 색상, 배경·형광펜·강조색 프리셋, 사진 배경, 내 프리셋 저장
- **말풍선** — 말풍선 넣기(왼쪽·오른쪽, 꼬리·이름 옵션), 말풍선 색상, 말풍선 프리셋
- **레이아웃** — 여백·글자 크기·자간·행간, 정렬, 저장 폭 또는 비율 고정(1:1, 4:5, 3:4, 9:16)

로그 입력창 바로 아래의 서식 도구는 어느 탭에서든 쓸 수 있습니다. 굵게·기울임·밑줄·취소선, 강조색, 형광펜, 제목/소제목, 인용선, 구분선을 지원합니다.

## 저장

PNG·JPG로 내보냅니다. 형광펜, 말풍선 꼬리, 구분선은 캔버스에 직접 그려 선명하게 출력됩니다. 파일은 `로그.png` / `로그.jpg`로 저장됩니다.

## GitHub Pages로 올리기

1. 이 저장소를 GitHub에 올립니다. (`index.html`, `app.js` 두 파일이 루트에 있으면 됩니다.)
2. 저장소 **Settings → Pages** 로 들어갑니다.
3. **Source** 를 `Deploy from a branch` 로 두고, 브랜치를 `main`(또는 기본 브랜치), 폴더를 `/ (root)` 로 지정한 뒤 **Save**.
4. 잠시 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 접속하면 됩니다.

파일이 두 개뿐이라 빌드 과정이 필요 없습니다. 그대로 열면 동작합니다.

## 로컬에서 실행

별도 서버 없이 `index.html` 을 브라우저로 열어도 되지만, 일부 브라우저는 `file://` 에서 웹폰트를 제한할 수 있습니다. 간단한 로컬 서버로 여는 것을 권합니다.

```bash
# Python이 있다면
python3 -m http.server 8000
# 그다음 http://localhost:8000 접속
```

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조와 스타일(모노톤 디자인 토큰, 라이트/다크, 반응형) |
| `app.js` | 편집기·서식·미리보기·이미지 저장 로직 |

웹폰트와 `html2canvas` 라이브러리는 CDN에서 불러옵니다. 인터넷 연결이 필요합니다.
