텍스트 대치

특정 글자를 다른 글자로 변환·삭제해요.
변환은 한 프리셋당 하나만 1:1로 지원해요.
삭제는 한 프리셋당 여러 개를 지원하며 쉼표로 구분해요.
저장한 프리셋을 클릭하면 입력과 미리보기에 바로 적용돼요.
예: ... → ⋯ / 바보 → 사랑해 / 케이크, 푸딩 → 삭제

↓

내 프리셋

지금의 설정을 저장해 두고 언제든 다시 불러올 수 있어요.
단, 배경 이미지는 프리셋에 저장되지 않아요.

초기화

전체 초기화: 프리셋을 제외한 모든 설정과 입력을 처음 상태로 되돌려요.
나머지 초기화: 각 프리셋에 저장된 내용을 초기화해요.

입력 도구

· *색*: *지문* 영역을 * 포함 *색*의 색깔로 변경해요.
· (색): (지문) 영역을 ( ) 포함 (색)의 색깔로 변경해요. 말풍선 안의 (지문)은 각 인물별로 지정된 (색)을 사용해요.
· (I): (지문) 영역을 ( ) 포함 이탤릭으로 변경해요.
· (Aa): (지문) 영역을 ( ) 포함 작은 글자 크기로 변경해요. 크기만 반영하기 때문에 색깔은 그대로 유지돼요.
· "넣": 문단의 앞뒤에 " "를 넣어요. 문단의 앞뒤에 *, ( ), 큰따옴표, 작은따옴표가 하나라도 있다면 적용되지 않아요.
· "색": "지문" 영역을 " " 포함 강조색으로 변경해요. 강조 1~6 중에서 고를 수 있으며, 적용 후에는 일반적인 강조와 똑같이 조정돼요.
· "말": "지문" 영역을 " " 포함 말풍선으로 변경해요. 바로 아래 줄에 (지문)이나 *(지문)*이 있으면 하나의 말풍선에 같이 들어가요.
· "인": "지문" 영역을 " " 포함 인용선으로 변경해요. 바로 아래 줄에 (지문)이나 *(지문)*이 있으면 하나의 인용선에 같이 들어가요. 인용선 1~6 중에서 고를 수 있으며, 적용 후에는 일반적인 인용선과 똑같이 조정돼요.

TIP!
· *색*과 (색)에 사용되는 색깔은 디자인-글자 · 보조에서 변경돼요.
· 말풍선 안의 (색)에 사용되는 색깔은 말풍선-인물에서 인물별로 변경돼요.
· 프리셋-텍스트 대치에서 특정 글자를 다른 글자로 변환·삭제할 수 있어요.

서식

· 강조·형광펜·인용선: 칠해진 뒤에도 각각 고유한 값을 가져요. 형광펜 1을 칠했다면, 나중에 형광펜 1의 색을 변경해도 이전 것이 반영돼요.
· 구분선 삭제: 백스페이스 또는 입력에서 직접 클릭 후 삭제할 수 있어요.
· 사진 정렬: 삽입 후에도 사진을 클릭해서 조정할 수 있어요.

TIP!
· 강조·형광펜·인용선을 삭제하고 싶을 경우, 칠해진 모든 영역을 드래그하는 대신 일부에 커서만 둬도 전체를 삭제할 수 있어요.
· ＋로 넣는 사진은 본문에 바로 들어가는 사진이에요. 말풍선처럼 사진을 넣고 싶다면 말풍선 삽입의 인물을 클릭하여 사진을 선택해 주세요.

말풍선

· 말풍선 삭제: 백스페이스 또는 클릭 시 나타나는 버튼으로 삭제할 수 있어요. 삭제 버튼을 사용할 경우 말풍선 안 내용은 그대로 유지돼요.
· 말풍선 이름: 말풍선 이름은 입력에서 조정 가능한 텍스트가 아니에요. 이름을 바꾸고 싶다면 인물에서 변경해 주세요.
· 말풍선 내 줄바꿈: 맨 앞·맨 뒤에서 이루어지는 엔터는 말풍선 밖으로 이동해요. 맨 뒤에서 줄바꿈을 하고 싶다면 Shift+Enter를 사용해 주세요. 모바일은 호환이 되지 않아 모든 글을 입력한 후 앞으로 이동하여 엔터를 눌러주세요.

말풍선 간격

· 말풍선 ↔ 말풍선 간격: 서로 다른 말풍선끼리의 간격이에요.
· 연속 말풍선 간격: 같은 인물, 같은 방향, 중간에 빈 문단이 없는 말풍선들을 연속 말풍선으로 처리해요. 이때 연속 말풍선끼리의 간격이에요.
· 말풍선 ↔ 본문 간격: 말풍선과 본문 글자 사이의 간격이에요. 말풍선과 말풍선 사이에 빈 문단을 만들거나, 말풍선과 글 사이에 띄어쓰기를 한다면 0으로 설정해야 내용-문단 간격의 수치만 적용돼요.
· 말풍선 아래에 빈 문단을 넣으면 말풍선 ↔ 본문 간격에 문단 간격이 더해져요.

말풍선 모양

· 아이메시지: 메시지를 추천해요. 그라데이션, 사진 배경의 경우 미리보기에서 말풍선 꼬리가 이상하게 뜨지만 저장 시 정상적으로 자리 잡아요.
· 심플: 메시지와 일반 대화를 모두 추천해요.
· 네모: 메시지와 일반 대화에 모두 호환되지만, 일반 대화를 추천해요.

TIP!
· 메시지: 프로필 사진 없는 대화.
· 일반 대화: 프로필 사진이 있는 대화.

프리셋

· 프리셋 종류: 인물, 삽입 방식, 텍스트 대치, 내 프리셋.
· 프리셋 순서: 모든 프리셋은 저장된 타원 부분을 꾹 클릭한 뒤 드래그하여 순서를 변경할 수 있어요.
